# AlphaGrowth × Cardano PRIME

A dark-mode public information site for the AlphaGrowth Cardano PRIME governance action.

It combines:

- a source-grounded summary of the 12-month PRIME program;
- a growth-focused hero centered on the 120M ADA dedicated to the program;
- an alphabetized, roster-derived view of the broader Cardano DeFi ecosystem;
- the final August 12, 2026 snapshot of verified on-chain stakeholders, ordered by voting power, with 16M+ ADA stakeholders shown by default and the full roster available on demand;
- source-verified public profile images or organization marks for 128 of those DReps, with neutral monograms for unmatched identities;
- public perspectives from builders and contributors across the Cardano ecosystem.

The public interface is static HTML, CSS, and JavaScript, with the stakeholder roster grounded in public on-chain sources.
